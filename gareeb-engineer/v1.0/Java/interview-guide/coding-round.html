Coding Round in Java

How to approach a live coding round, the Java APIs and idioms that save time, problem patterns with templates, and worked solutions to the problems asked most often.

  • Medium
  • Java
  • Interview Preparation
  • Data Structures
  • Algorithms
  • Coding Interview
~3 min read Updated Nov 11, 2026

Almost every Java interview includes a coding round, from a simple string program at a service company to two algorithm problems in 45 minutes at a product company. This page focuses on doing it in Java: the APIs and idioms that make solutions short and correct, the common patterns, and worked solutions. For the data structures themselves, see the Data Structure section of this site.

At a glance

Weightage

9 / 10

Who gets asked

Everyone.

Preparation time

Ongoing: 2 to 3 problems a day for 3 to 4 weeks

Handbook questions

Q111-Q113 (and Q114 for the singleton)

Builds on

Collections, Streams

How to run the round

  1. Clarify (2 to 3 minutes). Restate the problem. Ask about input size, empty input, duplicates, negative numbers, character set (ASCII or Unicode), and whether to return indices or values.

  2. Examples. Walk through one normal and one edge case by hand.

  3. Brute force first. State it and its complexity in one sentence. It shows you can solve the problem at all.

  4. Optimise. Name the pattern (hash map, two pointers, sliding window, heap) and the new complexity before coding.

  5. Code cleanly with clear names. Talk while you write.

  6. Test by running your examples through the code by hand, then the edge cases.

  7. Complexity. State time and space at the end, and what you would change for larger inputs.

Interviewers grade communication and testing as well as correctness. A clean, explained O(n log n) solution often scores better than a silent, buggy O(n) one.

Worked solutions

Two Sum: indices of two numbers that add up to a target.

Store each number’s index in a map and look up the complement. O(n) time, O(n) space.

static int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> indexOf = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        Integer j = indexOf.get(target - nums[i]);
        if (j != null) return new int[]{j, i};
        indexOf.put(nums[i], i);
    }
    return new int[0];
}
Valid parentheses.

Push expected closers; on a closer, it must match the top. O(n) time and space.

static boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        switch (c) {
            case '(' -> stack.push(')');
            case '[' -> stack.push(']');
            case '{' -> stack.push('}');
            default -> { if (stack.isEmpty() || stack.pop() != c) return false; }
        }
    }
    return stack.isEmpty();
}
Longest substring without repeating characters.

Sliding window: remember the last index of each character and move the left edge past a repeat. O(n) time, O(alphabet) space.

static int longestUnique(String s) {
    Map<Character, Integer> last = new HashMap<>();
    int best = 0;
    for (int left = 0, right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (last.containsKey(c) && last.get(c) >= left) {
            left = last.get(c) + 1;
        }
        last.put(c, right);
        best = Math.max(best, right - left + 1);
    }
    return best;
}
Top K frequent elements.

Count with a map, then keep a min-heap of size k by frequency. O(n log k) time, O(n) space. Mention bucket sort for O(n) if asked.

static List<Integer> topK(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    for (int n : nums) count.merge(n, 1, Integer::sum);

    PriorityQueue<Map.Entry<Integer, Integer>> heap =
            new PriorityQueue<>(Map.Entry.comparingByValue());
    for (var e : count.entrySet()) {
        heap.offer(e);
        if (heap.size() > k) heap.poll();
    }
    List<Integer> result = new ArrayList<>();
    while (!heap.isEmpty()) result.add(heap.poll().getKey());
    Collections.reverse(result);
    return result;
}
First non-repeated character.

Count while keeping insertion order, then return the first with count 1. O(n) time. For full Unicode, iterate code points (s.codePoints()) instead of chars.

static Character firstUnique(String s) {
    Map<Character, Integer> count = new LinkedHashMap<>();
    for (char c : s.toCharArray()) count.merge(c, 1, Integer::sum);
    for (var e : count.entrySet()) {
        if (e.getValue() == 1) return e.getKey();
    }
    return null;
}
Detect a cycle in a linked list (Floyd’s algorithm).

A slow pointer moves one step, a fast pointer two. If they meet, there is a cycle. O(n) time, O(1) space. To find the start of the cycle, reset one pointer to the head and move both one step until they meet.

static boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
Reverse a linked list.

O(n) time, O(1) space.

static ListNode reverse(ListNode head) {
    ListNode prev = null, current = head;
    while (current != null) {
        ListNode next = current.next;
        current.next = prev;
        prev = current;
        current = next;
    }
    return prev;
}
Merge overlapping intervals.

Sort by start, then extend or append. O(n log n) time.

static int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
    List<int[]> merged = new ArrayList<>();
    for (int[] in : intervals) {
        if (merged.isEmpty() || merged.getLast()[1] < in[0]) {
            merged.add(in);
        } else {
            merged.getLast()[1] = Math.max(merged.getLast()[1], in[1]);
        }
    }
    return merged.toArray(new int[0][]);
}

getLast() is Java 21 (sequenced collections); use merged.get(merged.size() - 1) on older versions.

Binary search, including the first position of a target.

O(log n).

static int firstIndexOf(int[] a, int target) {
    int lo = 0, hi = a.length - 1, answer = -1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] >= target) {
            if (a[mid] == target) answer = mid;
            hi = mid - 1;                 // keep searching left
        } else {
            lo = mid + 1;
        }
    }
    return answer;
}
Number of islands (grid BFS/DFS).

Each unvisited land cell starts a flood fill. O(rows × cols) time.

static int islands(char[][] grid) {
    int count = 0;
    for (int r = 0; r < grid.length; r++) {
        for (int c = 0; c < grid[0].length; c++) {
            if (grid[r][c] == '1') {
                count++;
                sink(grid, r, c);
            }
        }
    }
    return count;
}

static void sink(char[][] g, int r, int c) {
    if (r < 0 || c < 0 || r >= g.length || c >= g[0].length || g[r][c] != '1') return;
    g[r][c] = '0';
    sink(g, r + 1, c); sink(g, r - 1, c); sink(g, r, c + 1); sink(g, r, c - 1);
}

For very large grids, use an explicit queue to avoid StackOverflowError.

Subarray sum equals k.

Prefix sums plus a map of how many times each prefix sum occurred. O(n).

static int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> seen = new HashMap<>(Map.of(0, 1));
    int sum = 0, count = 0;
    for (int n : nums) {
        sum += n;
        count += seen.getOrDefault(sum - k, 0);
        seen.merge(sum, 1, Integer::sum);
    }
    return count;
}
Coin change: minimum number of coins.

Bottom-up DP: dp[a] is the fewest coins for amount a. O(amount × coins) time.

static int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);           // "infinity"
    dp[0] = 0;
    for (int a = 1; a <= amount; a++) {
        for (int coin : coins) {
            if (coin <= a) dp[a] = Math.min(dp[a], dp[a - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
Group anagrams.

The sorted characters form the key. O(n × m log m) for n words of length m.

static Collection<List<String>> groupAnagrams(String[] words) {
    Map<String, List<String>> groups = new HashMap<>();
    for (String w : words) {
        char[] chars = w.toCharArray();
        Arrays.sort(chars);
        groups.computeIfAbsent(new String(chars), k -> new ArrayList<>()).add(w);
    }
    return groups.values();
}

Classic Java programs (service company rounds)

Reverse a string without library reverse, and check a palindrome. 
static String reverse(String s) {
    char[] c = s.toCharArray();
    for (int i = 0, j = c.length - 1; i < j; i++, j--) {
        char t = c[i]; c[i] = c[j]; c[j] = t;
    }
    return new String(c);
}

static boolean isPalindrome(String s) {
    int i = 0, j = s.length() - 1;
    while (i < j) {
        if (s.charAt(i++) != s.charAt(j--)) return false;
    }
    return true;
}
Check whether a number is prime, and print primes up to n (sieve). 
static boolean isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; (long) i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}

static List<Integer> primesUpTo(int n) {
    boolean[] composite = new boolean[n + 1];
    List<Integer> primes = new ArrayList<>();
    for (int i = 2; i <= n; i++) {
        if (!composite[i]) {
            primes.add(i);
            for (long j = (long) i * i; j <= n; j += i) composite[(int) j] = true;
        }
    }
    return primes;
}
Fibonacci: recursive, memoised and iterative. 
static long fibIterative(int n) {
    long a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        long next = a + b;
        a = b;
        b = next;
    }
    return a;
}

Naive recursion is O(2ⁿ); memoisation and iteration are O(n). See Fibonacci Series for all versions.

Swap two numbers without a temporary variable. 
a = a + b; b = a - b; a = a - b;     // can overflow
a = a ^ b; b = a ^ b; a = a ^ b;     // XOR version; zeroes the value if both are the same array slot

Mention that a temporary variable is clearer in real code.

Find the missing number in 1..n. 
static int missing(int[] nums, int n) {
    long expected = (long) n * (n + 1) / 2;
    long actual = 0;
    for (int x : nums) actual += x;
    return (int) (expected - actual);
}
Thread-safe singleton.

Prefer an enum, or the holder idiom; in Spring, a singleton bean.

public enum IdGenerator {
    INSTANCE;
    private final AtomicLong next = new AtomicLong();
    public long nextId() { return next.incrementAndGet(); }
}

Machine-coding rounds

Some companies give 60 to 90 minutes to build a small working system: parking lot, elevator, splitwise, library management, rate limiter, LRU cache. They grade class design, SOLID, extensibility, and working code over completeness. The Low Level Design section and its design patterns page cover the approach.

Common traps

  • a - b in comparators.

  • (lo + hi) / 2 overflow.

  • int overflow in products and sums: use long.

  • Comparing Integer objects with == (works only from -128 to 127).

  • Using Stack or LinkedList instead of ArrayDeque.

  • Forgetting empty input and single-element input.

  • Modifying a collection while iterating over it.

  • Recursion too deep on large inputs.

Follow-ups to expect

  • "Can you do it in O(1) extra space?"

  • "What if the input does not fit in memory?" (Streaming, external sort, partitioning by hash.)

  • "What if this runs concurrently?"

  • "Write tests for your function."
